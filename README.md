## 📂 Estructura del Proyecto

El código está organizado en carpetas por cada ejercicio. Cada carpeta contiene su propio archivo `Main.java` para poder probarlo por separado:

- `Ejercicio1/`: Clase EventoUniversitario básica y constructor de copia
- `Ejercicio2/`: Incorporación de Sala, Actividad, Estudiante e Inscripción
- `Ejercicio3/`: Versión final con Herencia (Charla/Taller), polimorfismo y cálculo de costos
- `mapadememoria.png`: Gráfico del mapa de memoria solicitado en el Ejercicio 4
- `capturaejecucion.png`: Captura de la ejecución exitosa del programa

## 🚀 Cómo Ejecutar

1. Clonar o descargar este repositorio
2. Abrir la carpeta del proyecto en **IntelliJ IDEA**
3. Buscar la carpeta del ejercicio que se desea probar (Ejercicio1, Ejercicio2 o Ejercicio3)
4. Abrir el archivo `Main.java` y presionar el botón verde de "Ejecutar" (Play)
